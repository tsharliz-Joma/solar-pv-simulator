# solar-pv-simulator

## Description 
This is a solar pv simulator that is outputs a 24-hour hourly array of solar output values and a line graph showing output overtime.

## Project scope

### What does the simulator aim to model?
This simulator (assuming perfect weather) aims to model solar output hour by hour.

### At what level of detail?
At a very high level, it will out basic summary values (eg. peak output)

### Over what time resolution?
24 hours
1 timestep = 1 hour

## What is project is not

This project will not have or include
- No batteries
- No money
- No grid limits
- No forecasting
- No optimising anything
- No predictions for future
- No real weather data
